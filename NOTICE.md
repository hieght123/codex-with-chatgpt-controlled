# Release Checklist

This directory is a publication candidate, not a copy of a personal Codex installation.

Before creating a public repository:

1. This profile derives its controlled C2C workflow from XiaoDuoYa/codex-with-chatgpt. The upstream project is released under the MIT License; this repository retains the corresponding license text.
2. Confirm that no personal path, username, workspace name, connector address, tunnel configuration, token, pairing code, log, screenshot, or local backup is included.
3. Review every tracked file by allowlist. Do not upload an entire local configuration or runtime directory.
4. Test the profile in a disposable workspace with a read-only connector before claiming that it is reproducible.

The public profile describes a deployment pattern. Each user must provide their own approved workspace and local browser-runtime configuration.
